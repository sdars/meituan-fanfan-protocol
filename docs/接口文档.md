## 2. 通用请求头/签名

所有请求在发出前经 `@mtfe/weapp-safety-request` → `jsguard.signWithSiua(options)` 注入:

- `header.mtgsig` : JSON 字符串 (见 `算法原理.md`)
- 业务拦截器 (`api/interceptors.js`) 追加:
  - `header.mt-c-token` = 用户 token (addMcToken)
  - `header.deviceid`   = 设备 ID (addDeviceId)
  - `data.lat` / `data.lon` = 经纬度 (addOadParams)
  - `data.xcxVersion`   = 小程序版本 (addAppBaseInfoParams)

响应处理 (`returnData`): `ret === 999999` 表示登录态失效, 触发重登。

## 3. 登录链路 (open.meituan.com)

| 步骤 | 方法 | Path | 请求 | 返回 |
|---|---|---|---|---|
| getWxIds | POST(form) | `/user/thirdinfo/getweappuserinfo` | `{code, appName}` | `{openId, openIdCipher, unionId}` |
| silentLogin | POST(form) | `/user/v1/weappsilentlogin` | `{wechatFingerprint, code}` | `{token, userId, openId, openIdCipher, unionId, data}` |
| getMtInfo | GET | `/user/v1/info?token=&fields=` | - | `{user:{id,username,avatarurl,...}}` |
| 其它 | - | `/user/settings`, `/user/v2/weappgetmobilelogin`, `/user/v2/weappbindmobileloginapply`, `/user/v2/weappbindmobilelogin`, `/thirdlogin/wechatapplogout`, `/thirdlogin/user/h5/sharelogin/generateTicket` | - | - |

请求包装 (`re`):
- URL 经 `te()` 追加 query: `sdkVersion, utm_medium, joinkey, sdkType=wxmp, login_sdk_version,
  appName, risk_app, risk_partner, risk_platform, version_name, token_id, uuid` (空值不追加)。
- body 合并 `device_type`(=设备 model)、`device_os="微信小程序"`。
- 表单请求 content-type = `application/x-www-form-urlencoded`。

> **唯一外部输入**: `wx.login` 得到的 `code` (需真实微信环境)。
> `wechatFingerprint` 由 `finger.g()` 纯 Python 生成, 无需设备。

## 5. 用法示例

```python
import sys; sys.path.insert(0, "src")
from meituan_fanfan import LoginClient, LoginConfig, FanfanClient, Signer, UserState

# --- 登录 (code 来自真实微信 wx.login) ---
lc = LoginClient(LoginConfig(model="iPhone 13", platform="iphone", wx_version="8.0.40"))
fp = lc.signer  # wechatFingerprint 由 _finger.build_wechat_fingerprint 生成
info = lc.login(code="<wx.login code>", wechat_fingerprint="<finger.g 结果>")
print(info["token"], info["userId"])

# --- 业务请求 ---
user = UserState(token=lc.auth["token"], device_id="<deviceid>",
                 latitude=39.9, longitude=116.4, app_version="1.0.0")
cli = FanfanClient(signer=Signer(), user=user)
print(cli.fetchPointsBalance())
```

## 6. 受限项

- `code`: 必须由真实微信环境 `wx.login` 获取, 纯协议侧无法凭空生成。
- `device_type` / `sdkVersion` / `utm_medium` 等设备字段: 真机由 `wx.getSystemInfoSync()` 提供;
  纯协议侧使用配置值即可 (服务端不校验设备字段与签名的一致性)。
- `env_flag` (mtgsig 的环境自检位): 真机微信小程序取值需实测确认; devtools 桩环境实测为 `123`,
  本实现 `Signer.env_flag` 默认 `6` (真机微信小程序常见值), 可按环境调整。
