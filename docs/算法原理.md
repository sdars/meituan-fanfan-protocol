# 签名算法原理

> 来源: `npm/@mtfe/wx-jsguard/dist/jsguard.js` (jsguard 1.6.5)。
> 全部为纯 Python 静态复现, 无动态转发。验证代码见 `tests/test_protocol.py`。

## 1. mtgsig (ee / signWithSiua)

请求 header `mtgsig` 是一个 JSON 字符串, 字段:

| 字段 | 含义 |
|---|---|
| a1 | 协议版本 `"1.2"` |
| a2 | 毫秒时间戳 `Date.now() + serverTimeDiff` |
| a3 | dfpId (设备指纹 ID) |
| a4 | 48 hex 摘要 |
| a5 | 主密文 (自定义 base64) |
| a6 | siua 指纹串 (`finger.i()`) |
| a7 | appId |
| x0 | `3` |
| d1 | md5 混淆摘要 |

### 1.1 待签名串 w

`ee()` 构造 `w = encodeURIComponent(method + " " + path + " " + sorted_query)`,
再拼接 body 的 `encodeURIComponent` (上限 16200 字节)。

- query 解析后按 `(key, value)` 排序 (先 key 后 value), 每对 `enc(k)=enc(v)` 用 `&` 连接。
- GET: 把 data 对象展开为 query 对 (keep_undefined)。
- 表单 (`x-www-form-urlencoded`): body 走 `enc(k)=enc(v)`。
- 其它: body = `JSON.stringify(data)`。

实现: `signer.build_w()`。

### 1.2 a4 / a5 计算

```
l = K(i)                       # i 的 4 字节大端
g = W(siua) + l
v = md5_hex(g)
m = H(v[:15])                  # 前 15 hex -> 15 字节
m[7] = (env_flag ^ crc32(l)) & 255
m += l
m += K(crc32(m))
a5 = x_b64(m + cb(m, pc_json)) # 自定义 base64
S = murmur2(w, i)
A = murmur2(W(a5), i)
I = md5ToHex([S, A, S^i, S^A^i])
D = b2h(K(S) + K(A) + I)       # a4
```

### 1.3 d1 计算

```
T = a1 + str(i) + a3 + a4 + str(A) + v + a7
j = md5Array(W(T))
N = rol(i, x0)                 # (i << x0) | (i << (32-x0))
j[0] ^= N; j[1] ^= A; j[2] ^= A ^ N; j[3] ^= j[0]
d1 = md5ToHex(j)
```

### 1.4 关键坑 (已修复)

- **CRC32 常量**: jsguard 源码里多项式写的是**十进制 `3988292384`** (= 0xEDB88320),
  最终异或常量是**十进制 `306674911`** (= 0x12477CDF), **不是** 0x306674911。
  之前的 FAIL 根因即此。
- `md5ToHex`: 每个 32 位字按字节小端拆 4 字节, 每字节**低半字节在前** (`%02x` 逆序)。

实现: `_mtgsig.sign()`。

## 2. 自定义 VM (cb / rc4)

a5 密文 = `m + cb(m, pc_json)`。`cb` 是一段 jsguard 自实现的 RC4 变体:

```
# KSA: s = range(256); o=0
for i in range(256):
    o = (o + s[i] + m[i % len(m)] + 31) % 256
    swap(s[i], s[o])
# PRGA: i=0;o=0
for b in pc_bytes:
    o = (o+1)%256; i = (i+s[o])%256; swap(s[o], s[i])
    out.append(pc_byte ^ s[(s[o]+s[i])%256])
```

自定义 base64 字母表:
`VC = "ZmserbBoHQtNP+wOcza/LpngG8yJq42KWYj0DSfdikx3VT16IlUAFM97hECvuRX5"`
(标准 base64 的 `+/` 换成 `+w`, 其余按 VC 重排; 带 `=` 填充)。

实现: `_vm.cb()` / `_vm.rc4_prga()` / `_vm.x_b64()`。

## 3. 指纹 siua (finger.i)

```
siua = "w1.2" + base64(AES-128-CBC(key, iv, PKCS7(gzip(JSON(DFP 数组)))))
key = b'z7Jut6Ywr2Pe5Nhx'
iv  = b'0807060504030201'
```

DFP 数组 (9 项, 键序 `_e.DFP`):
```
[app, dfpid, filetime(毫秒), fpv="1.6.5", localid, system(42 项), timestamp(秒), ext=[0,0,null,0], sessionId]
```
`system` 的 42 项键序见 `_finger.SYSTEM_FIELDS` (与 jsguard `_e.system` 一致)。

AES key/iv 来自 jsguard 中两段 hex (`91EB...`, `C5F5...`): 取首字节作异或 key,
逐字节异或还原。

实现: `_finger.build_siua()` / `_finger.aes_gzip()`。

## 4. localId / dfpId (jc)

```
localId = str(ts) + randAZ(7) + md5(JSON(n)) + str(crc32(base))[:4]
n = {"model"?, "system", "openid"?}   # 键序固定, undefined 丢弃
```

无服务器下发 dfpId 时 `dfpId = localId`。服务器可通过 `/v1/wxdfpid` 下发 dfpId + serverTimeDiff。

实现: `_finger.build_local_id()`。

## 5. wechatFingerprint (finger.g)

登录接口 `weappsilentlogin` 的 `wechatFingerprint`:

```
wechatFingerprint = "WX__ver1.2.0_CCCC_" + base64(AES-CBC(gzip(JSON(t))))
```

其中 `t` 是对运行时对象 `Dc` 的变换副本: 删除 `fsmode / e / ext / system.gyro / dp / sessionId`;
若 `system.StorageInfo` 存在, 解析后清空 `keys` 再序列化。

实现: `_finger.build_wechat_fingerprint()`。
